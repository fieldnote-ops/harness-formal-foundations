# Harness 工程的形式化基础

**模型论与系统论视角下的分析框架与源码学习笔记**

锵与D老师 著

[在线阅读](https://fieldnote-ops.github.io/harness-formal-foundations/) · [下载 PDF](https://fieldnote-ops.github.io/harness-formal-foundations/harness-formal-foundations.pdf) · [问题反馈](https://github.com/fieldnote-ops/harness-formal-foundations/issues)

## 写作目的

本项目从编码智能体的工程实现出发，尝试为 Harness 工程梳理一套分析框架，帮助读者理解提示词、工具、上下文、权限与运行控制如何共同组织智能体的行为。

材料以 **Oh My Pi（OMP）与 deepseek-tui 的历史版本**作为源码阅读和比较学习的主要案例，将具体实现与模型论、系统论及控制论中的概念联系起来，讨论不同设计选择背后的约束与权衡。

希望这些分析能为阅读其他智能体项目、讨论架构问题，以及设计自己的 Harness 提供参照。

## 关注的问题

- 提示词、工具定义与权限规则如何共同约束智能体行为？
- 上下文、会话和扩展机制如何分层，各层之间如何保持一致？
- 工具与插件的加入会改变系统的哪些行为边界？
- 成本、可靠性与灵活性如何影响压缩、缓存和反馈控制？
- 不同实现之间有哪些可以比较、借鉴的设计选择？

## 分析方法与内容

模型论提供描述语言、约束、解释与满足关系的概念工具；系统论从整体性、层次性、开放性和目的性组织架构分析；控制论用于讨论运行时的反馈与调节。

全书分为三篇、八章：

| 篇章 | 内容 |
| --- | --- |
| 第一篇：形式语言 | 模型论基础，以及这些概念在 Harness 分析中的应用 |
| 第二篇：系统论架构 | 整体性、层次性、开放性与目的性 |
| 第三篇：综合 | 案例比较、框架综合与后续探索方向 |

## 如何阅读

希望了解分析语言的读者，可以从第一、二章开始；关注具体架构问题的读者，可以按主题阅读第三至六章，再结合第七章比较两个案例。

本材料属于探索性的分析与学习整理。文中的形式化映射、推导和示意模型需要结合各自假设阅读；理论出处、源码引注与适用边界仍有待进一步核对和完善。

欢迎通过 Issues 指出概念、推导、案例事实或排版问题。反馈时请附章节位置、相关原文，以及可核对的资料或源码版本。
